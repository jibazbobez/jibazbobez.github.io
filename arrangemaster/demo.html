The Purpose of the Demo

The primary objective of this demo is to allow you to test file compatibility. It demonstrates how robustly Arrange Master processes your specific files - including heavy prepress vectors, compound clipping masks, dynamic symbols, and multi-layer structures - without freezing or crashing Adobe Illustrator.

Included Demo Features

  • Two Layout Methods: Test the standard Grid Layout and the bounding-box based Knolling Layout (MER algorithm).
  • Multi-Layer Retention: Preserves complex prepress files (separate CUT, PRINT, QR layers) by temporarily clustering overlapping objects and safely restoring them to their original layers upon clicking OK.
  • Clipping Mask Support: Detects accurate boundaries of masked objects, ignoring hidden bleeding contents.
  • Smart Container Detection: Automatically identifies the layout container by calculating the largest area in your selection.

Why are there empty spaces between arranged objects?

When using the demo, you will notice empty gaps between irregularly shaped objects instead of a tightly interlocked layout. This occurs because the demo version uses a simplified Knolling Layout algorithm. It arranges objects based strictly on their rectangular bounding boxes (geometricBounds) and cannot analyze physical, irregular contours.

The Session Workflow: Why you must click "OK"

Arrange Master operates on a strict, non-destructive session model. When you click Arrange, the script does not modify your original objects. Instead, it hides them and creates a temporary working group containing duplicates. This allows you to safely test different parameters or click Randomize without losing your original layout.

To finalize the process, you must click OK. This action deletes your hidden originals, ungroups the temporary items, and automatically redistributes them back to their initial Z-order and specific layers (e.g., CUT, PRINT). If you close the window or click Cancel, the script simply deletes the temporary group and unhides your original artwork, reverting everything to its initial state.

What is a JSX Script?

A .jsx file is a simple script for Adobe applications. Unlike a full plugin (.zxp), it doesn't require a special installer. You can run it directly from Illustrator's menu.

How to Install and Run

You can try Arrange Master in seconds without any installation. For regular use, we recommend placing the script in the Illustrator folder.

Quick Run (No Installation)

  1. Download the script using the button in the header to get the Arrange Master Demo.jsx file.
  2. In Adobe Illustrator, select your objects (a container and some items).
  3. Go to the menu: File > Scripts > Other Script... (or press Cmd+F12 / Ctrl+F12).
  4. Navigate to and select the downloaded Arrange Master Demo.jsx file to run it.

Recommended for Regular Use (Installation)

To have the script always available in your menu:

  1. Place the downloaded script into your Adobe Illustrator Scripts folder. Common locations are:
    • Windows: C:/Program Files/Adobe/Adobe Illustrator [Version]/Presets/en_US/Scripts/
    • macOS: /Applications/Adobe Illustrator [Version]/Presets.localized/en_US/Scripts/
  2. Restart Illustrator. This is a one-time step.
  3. Now you can run the script anytime from File > Scripts > Arrange Master Demo.
