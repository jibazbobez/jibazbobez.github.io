Arrange and nest artwork
in Adobe Illustrator.

Arrange Master is a layout plugin for Adobe Illustrator. Build grids, pack pieces by their outlines with True-Shape Nesting, or fill a custom shape.

Use vectors, raster images or mixed selections. Set the spacing and rotations, follow the live preview, then apply the layout or restore your original artwork.

02 / Four layout methods

Choose a layout method.

Use cells for a grid, rectangular bounds for raster images or Dense Packing for vector outlines. Shape Respect places objects inside a custom boundary.

Dense Packing

Nest irregular vector shapes by their outlines rather than the bounding box around them. Use it for sticker sheets, decal kits and cut parts.

Start with
One rectangular container, your minimum spacing and allowed rotations.
Then adjust
Increase Genetic Algorithm effort when a tighter result is worth more time. Watch the best layout update in the preview.
Also included
Single Item Fill, Disperse and Align Final Edge.

Grid Layout

Arrange selected objects in rows and columns. Each object gets a cell, so you can organise different icons, illustrations or catalog images.

Start with
The row and column count. A grid draft appears in the panel before you arrange.
Then adjust
Offset alternate rows, use square cells or introduce size and rotation variation.
Remember
A piece must fit its cell unless Size Limit Off is enabled.

Bounds Packing

Pack objects using their rectangular bounding boxes. Use it for raster images, grouped artwork and layouts that need space around each object.

Start with
0° rotation for upright images, then choose a fill direction and spacing.
Then adjust
Use Fit to Container if all objects may be scaled together.
Remember
Transparent pixels in a raster image do not become a cut contour.

Shape Respect

Fill a letter, logo or other shape with selected artwork. The container can include holes and separate regions.

Start with
A clean container boundary and enough source artwork to fill it.
Then adjust
Change spacing and allowed rotations; enable Disperse to spread objects more evenly across the shape.
Also included
Single Item Fill for repeating one design throughout the usable shape.

03 / Single Item Fill

Fill a sheet with copies
of one design.

Repeat one sticker, label or vector part inside a container. Single Item Fill uses the spacing and rotations you choose.

Start with one design.

Select one grouped design and a container, then enable Single Item Fill. The plugin creates and arranges the copies.

Use a sheet or a custom shape.

Choose Dense Packing for a rectangular sheet or Shape Respect for a custom outline. Holes in the container remain empty.

Check the copies before applying.

Review the copy count and gaps. Apply keeps the arrangement; Cancel restores the source artwork.

04 / Disperse

Distribute objects evenly within any shape.

Disperse spreads selected objects across the container. Use it when you want space between motifs rather than a tightly packed group.

Leave space between motifs.

Spread illustrations across a rectangle or inside a logo, letter or decorative shape.

Follow the container’s outline.

Enable Disperse in Dense Packing for a rectangle, or in Shape Respect for a custom outline. It moves the selected objects without making copies.

Adjust spacing and compare the result.

Set the minimum gap and allowed rotations. The shapes and container affect the spacing, so check the preview and any unplaced objects.

05 / Artwork & preparation

Keep artwork and cut lines together.

Arrange vectors, images and text in the same selection. Prepare each design so its components move together.

Use mixed artwork.

Combine paths, text, groups, symbols, clipping masks and images. Raster images use rectangular bounds. Opacity masks are not supported.

Keep print and cut parts together.

Align each design’s components directly above one another distributing them on different layers. Group the print artwork or use a clipping mask, and keep the cut line within its print bounds.

Inspect the file before output.

Check registration, spacing and layer order in the Illustrator document. Save after applying the layout.

06 / Preview & sessions

Review the layout
before you apply it.

Watch the layout in the panel preview. Try other settings or another method, then finish the session with Apply or Cancel.

01

Save first and stay in one document.

Save before starting. For complex files with many objects, clipping masks or layers, keep only one document open. Finish the session before switching documents.

02

Select artwork and a container.

The largest selected object is the container. Group the parts that should move together before starting.

03

Choose spacing and allowed rotations.

Set the method, gap and permitted rotations. Leave resizing options off when the original dimensions must stay unchanged.

04

Run Arrange and compare the preview.

Click Arrange. Wait for the operation to finish before editing; you can then change settings and arrange again in the same session.

05

Finish the session with Apply or Cancel.

Apply keeps the layout and ends the session. Cancel restores the originals. Finish before switching files or closing the panel.

12 / Frequently asked questions

Using Arrange Master.

Answers about nesting, artwork preparation, trial keys and licenses.

How do Arrange Master and Arrange Master PRO differ?

Arrange Master includes four layout methods, Single Item Fill, Disperse and a panel preview with a lifetime license. Arrange Master PRO powered by the fast and precise Dance Fusion engine, adds automatic additional containers and a larger preview for multi-sheet jobs. PRO uses a subscription.

Which method should I use for a sticker sheet?

Use Dense Packing for different vector outlines, Single Item Fill for copies of one design, or Grid Layout for rows and columns. Set the gap for your print and cutting process.

Will Arrange Master resize my artwork?

Dense Packing and Shape Respect keep the source dimensions. Bounds Packing can resize the collection when Fit to Container is enabled. Grid’s Vary Size can also change sizes; keep it at 1 to leave them unchanged.

Can I mix images, text and vector objects?

Yes. Group the parts of each design or prepare aligned components before arranging. Clipping masks are supported. Raster images use rectangular bounds, including transparent pixels. Opacity masks are not supported.

Can I keep my cut lines on a separate layer?

Yes, with a prepared file. Align related components, group the print artwork or use a clipping mask, and keep its cut line within the print bounds. Check registration after arranging.

When do the 24 hours start?

At the first successful activation on one computer. Requesting a key or downloading the plugin does not start the clock. Reinstalling or releasing a device does not restart the trial.

What happens when the pieces do not all fit?

Unplaced items go above the container. Apply the layout and arrange the remaining pieces with another container in a new session. Automatic additional containers are a PRO feature.

What does the lifetime purchase include?

The purchased version has no subscription and includes free v1.x updates. Personal covers one computer, Team up to four and Extended Commercial up to ten. The licenses have different usage rights.

Does activation need an internet connection?

Yes. Activation, license checks and engine downloads need an internet connection. Keep it available during the trial.

Can I move my license to another computer?

Finish the session, open Settings → License and choose Release this device. Activate on the other computer with the same key. If the old computer is unavailable, contact info@andrewr.online.
